# OKX 全市場策略優先掃描器（研究版 v0.2）

**這是待實盤驗證的研究原型，不是已部署或已證實能獲利的交易系統。程式不使用 OKX API Key、不會下單。**

## 已實作

- 每30分鐘執行一次的 Render Cron 排程範例：`2,32 * * * *`（UTC，對應台灣每小時02分、32分）。
- 從 CoinGecko 市值排行榜依序取得至多200種**非穩定／非包裝**的加密貨幣，再交集比對 OKX `*-USDT-SWAP`；不把200個候選幣誤當200個真的可交易合約。
- 檢查 OKX `live`、上市至少90天、24小時推估交易量至少500萬美元、買賣價差不高於0.3%、最新報價時間；不因BTC/ETH/SOL調整策略。
- 策略A：日線25日均線負乖離／Z值、1H MACD(12,26,9)、4H、成交量與價格突破。
- 策略B：30m／1H／2H／4H／6H／8H／12H／1D共八個週期的*已確認普通MACD DIF底背離*，符合多週期共振後再要求價格突破及量能；8H由完整4H雙棒合成。
- 僅使用OKX已完結K線（`confirm=1`），不把MACD金叉誤認底背離。
- 單次研究訊號最多3種合約，包含合約、區間入場、止損、TP1、TP2、估算手續費／滑價／正資金費率後風報比、背離證據及有效期。
- ntfy推播（預設**關閉**，必須完成安裝、設定並確認研究風險才可開啟），透過ntfy最近訊息去重。**ntfy.sh未登入主題可以被知道主題名稱的人讀到**，請用20字以上隨機主題名稱或自建私有伺服器，不要公開主題。
- Fail-closed：當行情過時、缺失、交易所拒絕查詢、通知無法確認去重、風報不足時，不輸出交易提示。

## 尚未完成／限制

1. **尚未做2022–2026年歷史回測、樣本外驗證與實際紙上交易測試。** 八週期底背離不代表必定創高。
2. **尚未完成真實OKX行情端對端驗證**，因本地測試環境無法連線外網；目前只有合成／模擬資料邏輯測試。
3. 實際可覆蓋幣數取決於 CoinGecko 可用市值資料、OKX合約上架、流動性與 API 限速。CoinGecko可能需要免費Demo API Key。相同代號不同幣的映射採保守去重，部分真實合約可能漏檢。
4. Render Cron 是計費服務，會有至少約US$1/月的最低費用及依運作量額外費用。不要在未獲用戶同意付費前建立。
5. Render排程並不保證精準開盤後秒級執行；網路故障、API限速、平台中斷時可漏掉掃描，不是交易即時系統。
6. TP價格採近期已發生阻力位篩選，可能完全找不到1:2的合理目標；這時候不通知。風報比是估算，未計入個人等級手續費、完整訂單簿深度及極端跳空風險。
7. 僅做多研究訊號，做空策略尚未完成獨立回測。槓桿比例、強平價、帳戶淨值風險預算需由交易者自行確認。
8. ntfy公共服務的推播不屬於ChatGPT原生通知，使用者需自行安裝、訂閱；不保證iOS任何網路狀況皆即時收到。

## Render 部署簡述（無須懂Python，但須有GitHub存放庫及帳戶授權）

1. 把本資料夾的 `scanner.py`、`requirements.txt`、`render.yaml` 上傳到**新建的私有GitHub存放庫**。
2. 在 Render 選擇已授權的工作區與該GitHub repo，建立 Cron Job；`runtime=python`、`schedule=2,32 * * * *`、`buildCommand=pip install -r requirements.txt`、`startCommand=python scanner.py`、機型`starter`、區域`singapore`。
3. 第一次保持 `ENABLE_PUSH=false`、`RESEARCH_ACK=false`，觀察日誌中各輪掃描數量、資料錯誤與研究訊號。
4. 要手機推播才設定 `NTFY_TOPIC` 為難猜的長字串並在iPhone ntfy App訂閱同名主題；確認後再把 `ENABLE_PUSH=true`、`RESEARCH_ACK=true`。這將發出**研究訊號，不是可保證的交易建議**。
5. 遇到CoinGecko API限制，另申請Demo Key並設環境變數 `COINGECKO_API_KEY`，不要把Key寫進公開repo。

# 第三輪｜OKX 合約策略敏感度研究 v0.3

**研究程式，不下單、不使用 OKX 私人 API Key、不發送 ntfy 通知、絕不改動 Render 掃描服務。** 本程式不證明策略有獲利能力。

## 與第一／第二輪的差異

第三輪沿用倉庫 `historical_backtest.py` 的八週期指標與 OHLCV 下載函式，以及 `diagnostic_backtest.py` 的 A/B 訊號旗標，對照 **16 個預先固定的研究情境**：2 種原始基準，10 個條件單獨調整，2 個風報比／進場價格單獨調整，2 個成本加倍壓力測試。雙倍成本測試不算策略單條件移除試驗。

訊號判定沿用舊程式、於K線完全收盤後進行；下一根30分鐘K線的開盤價才可判斷是否能進場；出場使用往後K線；同根停損停利碰撞一律保守採停損優先。每個策略／每個商品獨立計算持倉冷卻，不把互相重疊的多個幣種模擬成真實投資組合。

## 第一輪執行設定

* 指定 **365天**、8個 USDT 永續合約：BTC / ETH / SOL / XRP / ADA / DOGE / LINK / AVAX。結束點固定為 `2026-10-01T00:00:00Z`，以免每次執行參照日期不同。
* 前 **90天只做指標暖機**，剩餘有效觀察窗口約275天（仍須排除缺少高週期指標與各分割期間最後48小時，精確時數以報告為準）。
* 依評估時間依序分割 **60%訓練／20%驗證／20%時間測試**，每個分割最後預留96根30m＝48小時，不讓已實現報酬從下一分割的 K 線洩漏回上一分割。
* 事先設定單邊費用 0.05%、單邊滑價 0.05%、每8h資金費率近似值 0.01%；並在特定變體做費用與滑價加倍檢驗。資金費率是保守但不一定符合實際的常數假設，並非真實歷史帳單。
* 基準情境 A_BASE / B_BASE 不改原始策略進出場／風報比門檻。A/B消融情境只變動一個指定條件；非基準情境只是研究假設。
* GitHub 工作流程建立在 `.github/workflows/okx-sensitivity.yml`，**推送本檔即自動跑一次365天**。之後可從 Actions → OKX Third Round Sensitivity Research v0.3 → Run workflow 手動選730天。730天會重新下載更多資料，耗時較長且有可能因 OKX 資料歷史長度不足失敗；失敗不會偽裝成完整分析。

## 結果檔案

`GitHub Actions → 最近一次 OKX Third Round → Artifacts` 可取得：

* `sensitivity_v03.json`：完整分割邊界、研究情境定義、每個變體的通過關卡與績效及資料涵蓋完整性。
* `sensitivity_v03.scenarios.csv`：逐策略、逐分割的訊號／風報比／進場淘汰及淨報酬統計。
* `sensitivity_v03.markets.csv`：逐合約、逐策略、逐分割的統計。
* `sensitivity_v03.trades.csv`：完成進出場的逐筆紀錄；若沒有交易會是只有表頭的空CSV，不得解讀為零風險。

所有數據都需明確區分「每30分鐘評估時點數」「原始訊號時點數」「完成交易筆數」；**同一訊號連續保留多個30分鐘區間不可算多筆獨立交易**。

## 方法與限制（必讀）

1. 本次一年試驗會與前兩輪的180天歷史期有重疊，因此第三輪所稱「時間測試」**不是從未看過的乾淨樣本外**。而且比較多種變體會帶來多重檢驗、擇優偏誤；不能用本次時間分割的勝率單獨宣稱已驗證獲利。
2. 使用**今天已知的8種大幣**回測過去，不包含過去各月真實的市值前200成員、下市商品、歷史交易深度及流動性偏差。不可將結果套用到「市值前200」全體。
3. 簡化模型未重建歷史 order book、實際每期資金費率、強平、部分成交、停損滑點分布、同時多幣持倉資金佔用。`illustrative_sequential_dd` **只是依序複利假設的交易回撤**，並非真實投資組合最大回撤。
4. 原程式的 MACD、底背離、目標價等僅使用當時已收盤K線；資料不足或缺失將讓執行失敗，不能以空值掩蓋。
5. 預先選定最低討論門檻：訓練交易≥40、驗證交易≥25、兩期淨平均收益>0、驗證 Profit Factor>1.1，且示意交易序列回撤<25%。**門檻只是初步篩選**，不是可實盤許可。最終的時間測試樣本少於100筆仍不能宣稱統計可靠。未來還需完全未看過的前瞻紙上交易及壓力測試。
6. 本次只評估做多原型；做空策略尚未建立，任何變體都**沒有**正式啟動通知。

## 在可存取 OKX 公開 API 的環境重現

在 `okx-monitor/backtest` 目錄：

```bash
python -m pip install -r requirements.txt
python -m unittest -v tests.py test_diagnostic.py test_sensitivity.py
python sensitivity_backtest.py --days 365 --warmup 90 --end-utc 2026-10-01T00:00:00Z --output sensitivity_v03.json
```

若環境不能連線 OKX，**只能測試本地合成行情與程式邏輯，不可宣稱已完成真實市場回測**。

## 安全與開啟正式訊號

新工作流程僅使用 `permissions: contents: read`；不需要 OKX 交易密鑰或 Render 變數。不會呼叫下單 API；不會觸及原本的 `scanner.py`、`render.yaml`、`ENABLE_PUSH`、`RESEARCH_ACK` 或 `NTFY_TOPIC`。正式通知應持續關閉，除非未來完成策略再驗證、前瞻紙上交易測試與人為明確確認。
